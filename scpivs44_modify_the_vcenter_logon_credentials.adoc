= Actualiza las credenciales de vCenter configuradas en SCV
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Usa esta tarea para actualizar las credenciales de inicio de sesión de vCenter configuradas en SnapCenter Plug-in for VMware vSphere. SCV usa estas credenciales para acceder a vCenter. Cuando cambie la credencial de vCenter, actualízala en SCV para que vCenter siga registrada en SCV. Para las copias de seguridad de vVol, anula el registro de ONTAP tools for VMware vSphere y luego vuelve a registrar ONTAP tools con la nueva contraseña para que las copias de seguridad sigan funcionando.

.Antes de empezar
Debe conocer la dirección IP y las credenciales de inicio de sesión para la interfaz de usuario de administración del SnapCenter Plug-in for VMware vSphere .  También debes anotar el token MFA generado desde la consola de mantenimiento.

* La dirección IP se mostró cuando se implementó el plugin de SnapCenter para VMware vSphere.
* Use las credenciales de inicio de sesión que se proporcionan durante la implementación del plugin de SnapCenter para VMware vSphere o como se modifican posteriormente.
* Genere un token MFA de 6 dígitos con las opciones de configuración del sistema de la consola de mantenimiento.


.Pasos
. Inicie sesión en la interfaz de usuario de administración del SnapCenter Plug-in for VMware vSphere .
+
Utilice el formato `\https://<appliance-IP-address>:8080`

. En el panel de navegación izquierdo, selecciona *Configuración*.
+
image:scpivs44_image30.png["SnapCenter Plug-in for VMware vSphere"]

. En la página *Configuración*, en la sección *vCenter*, selecciona *Editar*.
. Ingrese la nueva contraseña y luego seleccione *Guardar*.
+
No modifique el número de puerto.



.Después de terminar
Una vez guardadas las nuevas credenciales, comprueba que SCV sigue conectado a vCenter.

* En la interfaz de usuario de gestión de SnapCenter Plug-in para VMware vSphere, abre *Dashboard* y verifica que SCV está conectado a vCenter y habilitado.
* En el vSphere Client, verifica que se muestre el menú *SnapCenter Plug-in for VMware vSphere* y que las páginas del complemento se carguen.
* Opcional: Abre un grupo de recursos o ejecuta una copia de seguridad bajo demanda para comprobar que las operaciones de vCenter funcionan.


Si SCV no se conecta tras el cambio de credenciales, reinicia el servicio del cliente de VMware vSphere. Si SCV sigue sin conectarse, ve a link:scpivs44_post_deployment_required_operations_and_issues.html["Operaciones necesarias y problemas posteriores al despliegue para el SCV"].
